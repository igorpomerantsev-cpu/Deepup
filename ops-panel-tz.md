# ТЗ: доработка панели Lagomberry Ops (3 задачи)

Контекст: проект панели управления пекарней Lagomberry (папка `lagomberry/ops-panel`, рецепты хлеба лежат в `lib/methods.ts`, рядом есть `baking-plan/PLAYBOOK.md`). Выполняй задачи по порядку, в конце покажи диффы и краткий отчёт по каждому пункту.

## 1. Нечитаемый шрифт на телефоне в тёмной теме

Найди в панели все места, где цвет текста задан жёстко (hex/rgb) без учёта тёмной темы, либо где тёмная тема задаёт тёмный фон, не меняя цвет текста. Типовые виновники:

- текст, окрашенный в цвет «чернил» светлой темы поверх тёмного фона;
- вторичный серый текст с контрастом ниже WCAG AA (4.5:1);
- текст внутри цветных бейджей статусов.

Проверь и `prefers-color-scheme: dark`, и явный переключатель темы, если он есть. Проверь именно на мобильной ширине (≤ 430px) — в мобильной вёрстке могут быть свои стили.

**Критерий приёмки:** на телефоне в чёрной теме весь текст читается, контраст основного текста ≥ 4.5:1.

## 2. Кнопка «Изменить» в карточке заказа

В карточке заказа добавь кнопку изменения заказа — **только для заказов со статусом «новый»** (для остальных статусов кнопка не показывается или неактивна с подсказкой почему). По нажатию — редактирование состава заказа: позиции, количество, при необходимости дата/комментарий; пересчёт суммы; сохранение туда же, куда пишутся заказы сейчас (хранилище не менять). После сохранения статус остаётся «новый», в карточке видно, что заказ отредактирован (например, отметка «изменён» со временем).

## 3. Аудит рецептов: в синнаролле (Cinroll) пропал сахар

В рецепте Cinroll куда-то делся сахар — найди, когда и как он исчез (посмотри git-историю файла с рецептами: `git log -p -- lib/methods.ts` или где лежат рецепты), и верни его с правильной граммовкой из последней корректной версии.

Затем прогони проверку **всех** рецептов на целостность:

- у каждого рецепта каждый ингредиент из шагов есть в списке ингредиентов с ненулевым количеством;
- нет ингредиентов-сирот (объявлены, но нигде не используются);
- суммы/выходы батчей сходятся;
- сравни текущие рецепты с последней версией в git на предмет других случайно выпавших строк.

Выведи таблицу: рецепт → найденные проблемы → что исправлено.
